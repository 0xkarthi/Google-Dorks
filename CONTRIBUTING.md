# Contributing

Thanks for helping improve this educational Google search reference.

## Good contributions

- Fix typos, outdated operators, and broken formatting.
- Add short, accurate explanations for search operators.
- Improve organization and remove duplicate examples.
- Provide examples that use dummy domains or systems you own.

## Before opening a pull request

1. Check whether the example is already included in `Advance-Google-Dorks.md`.
2. Use placeholders such as `example.com` instead of real people, secrets, or private links.
3. Keep each edit focused and describe what changed.
4. Avoid submitting exposed credentials, personal information, or sensitive data obtained from search results.

## Safety and scope

Contributions should support education and authorized testing. Do not include instructions that depend on accessing systems without permission. If an example could reveal private information, replace it with a harmless demonstration.
