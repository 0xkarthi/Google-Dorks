# Google Dorks Reference

A collection of Google search operators and example queries for learning search techniques and supporting authorized security research.

## Contents

- [Advanced Google Dorks](Advance-Google-Dorks.md) — the main reference list.

## How to use

1. Open the reference document.
2. Adapt search operators to your own websites, test systems, or explicitly authorized scope.
3. Validate findings responsibly and avoid collecting private information.

## Responsible use

Search results can expose sensitive-looking content without giving permission to access, download, or disclose it. Respect applicable laws, site policies, and the authorization boundaries of any security assessment.

## Contributions

Corrections, clearer descriptions, and safely scoped educational examples are welcome through pull requests.
